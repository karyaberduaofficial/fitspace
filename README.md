# FitSpace — Integrated Fitness Center Management Platform

**FitSpace** adalah platform manajemen pusat kebugaran modern berbasis web dan *Progressive Web App* (PWA) yang dirancang untuk menghadirkan pengelolaan operasional studio dan layanan kebugaran lintas cabang secara terpadu, cepat, dan responsif di berbagai perangkat.

Platform ini menghubungkan kebutuhan pengelola studio, pelatih, member dewasa, serta orang tua/wali dalam satu pengalaman layanan yang terstruktur — mulai dari katalog kelas dinamis, penjadwalan studio, manajemen keanggotaan, pemesanan dan penyesuaian jadwal, pencatatan kehadiran digital, evaluasi perkembangan peserta, hingga pelaporan operasional dalam format **PDF**, **Excel (`.xlsx`)**, dan **Word (`.docx`)**.

---

## Fitur Utama

| Modul | Ringkasan Layanan |
| --- | --- |
| **Manajemen Multi-Cabang & Studio** | Pengelolaan cabang, ruangan studio, kapasitas sesi, dan operasional harian secara terpusat. |
| **Katalog Kelas Dinamis** | Pengelolaan kategori olahraga, tingkatan kelas, jadwal sesi, dan indikator penilaian secara fleksibel. |
| **Akses Berbasis Peran** | Pengalaman antarmuka khusus sesuai kebutuhan **Admin**, **Coach / Pelatih**, **Member (18+)**, **Orang Tua / Wali**, serta pratinjau **Akun Tamu**. |
| **Booking, Membership & Reschedule** | Pemesanan kelas per sesi maupun paket membership, dukungan voucher promo, serta penyesuaian jadwal sesuai kebijakan studio. |
| **Absensi & Evaluasi Perkembangan** | Pencatatan kehadiran kelas secara digital, distribusi materi latihan, penilaian perkembangan berkala, dan rapor peserta bagi orang tua/wali. |
| **Transaksi & Pelaporan Lengkap** | Pemantauan transaksi, rekap aktivitas operasional, serta ekspor laporan siap cetak dan olah data dalam format **PDF**, **Excel (`.xlsx`)**, dan **Word (`.docx`)**. |
| **Pengalaman Lintas Perangkat** | Antarmuka adaptif untuk smartphone, tablet, desktop, layar informasi studio, hingga perangkat pintar modern. |
